# 参照製品パリティ・チェックリスト

Mitama Island の設定画面と周辺 UI を、有償の参照製品（Vibe Island 1.0.43）と同等の情報設計に揃えるための対応表。
各フェーズの受け入れ基準はこの表であり、表の行がすべて ✅ になった時点でパリティ完了とする。

## この文書の使い方

- **状態**: ✅ 実装済み（UI と挙動が両方動く） / 🟡 一部のみ / ❌ 未着手・見送り・削除
- **2026-08-05 全行を実コードと突き合わせて訂正**。第1部で実装した項目が ❌ のまま残っており、
  この表自体が実態より遅れていた。以後、項目を実装したコミットで同時に更新する。
- **挙動依存**: 「UI を出すだけでは嘘になる」項目。`FeatureAvailability` に登録し、実装が入るまで disabled にする
- 参照製品の文言そのものは本書に転記しない。項目の**機能**を自分の言葉で記述する
- 参照製品の生の設定ツリー（文字列リソース・defaults ダンプ）は `.local-reference/` にローカル抽出してあり、gitignore 済み。公開リポジトリには入れない

## 1.5 視覚文法（実機スクリーンショットから）

コードに落とすときはここを基準にする。

| 要素 | 仕様 |
|---|---|
| ウィンドウ | ダーク固定。サイドバーは本文より暗い。角丸大 |
| サイドバー項目 | **色付き角丸スクエアのアイコンチップ + 白いグリフ**。SF Symbol に色を付けただけではない。選択行は薄いグレーの角丸背景 |
| アイコン色 | 一般=グレー / 統合=ティール / 通知=赤 / 表示=紫 / サウンド=緑 / 使用量=ピンク / ショートカット=マゼンタ / SSHリモート=青 / ラボ=オレンジ / パス=ティール / 情報=青 |
| 本文ヘッダ | サイドバーと同じアイコンチップ + ペイン名を大きめに |
| セクション見出し | 小さめのグレー文字、カードの外・左上 |
| 行 | 角丸カードを縦に連結し、行間はヘアライン。ラベル左、コントロール右 |
| 補助説明 | ラベルの直下、同じ行の中に小さいグレー文字で入る（別行にしない） |
| スライダー行 | ラベル左、**現在値を等幅フォントのピル**で右端に表示。スライダーは行の下段に置き、目盛りのドットを並べる |
| 選択行 | 値 + 上下シェブロン（`5s ⌄`） |
| トグル | 標準の青。無効時はグレー |
| ボタン | オレンジ（インストール/修復）、赤文字（アンインストール）、青文字リンク（CLIブランチを追加…） |
| 状態表示 | 緑チェック + 「有効」「インストール済み」、警告は⚠️オレンジ |
| バッジ | 「プリセット」は青、パターンは等幅 |
| 表示ペインのプレビュー | セッションカードの**実物大ライブプレビュー**が下部にあり、トグルの結果が即反映される |

## パネルのキーボード操作（A1・2026-08-04）

| 項目 | 状況 | 備考 |
|---|---|---|
| 承認・拒否・常に許可・権限スキップ・ターミナルへ | ✅ | Carbon の `RegisterEventHotKey`。**アクセシビリティ権限が要らない**ので、ターミナルで文字を打ち続けたまま ⌃Y で承認できる |
| 登録スコープ | ✅ | パネル展開中だけ登録し、閉じたら解除。単文字を常時奪うとエディタの操作を食うため、これが安全性の要 |
| キーボード配列の追従 | ✅ | `UCKeyTranslate` で実際の配列を読む。AZERTY で「A」を押したら A が出る。配列を切り替えると作り直す |
| 割り当ての重複・存在しないキー | ✅ | 先勝ちで1つだけ登録し、残りは設定側で理由を出す（黙って両方登録すると、どちらが動くかが辞書順で決まる） |
| 修飾キー押しっぱなしのヒント | ✅ | ボタンに文字を出す。**これだけはアクセシビリティ権限が要る**ので、未許可なら設定にその旨を出す（ショートカット自体は動く） |
| パネル内で打つキー（1–9 / ↩ / esc） | ❌ 準備中 | パネルがキーボードの入力先になる必要があり、意図的にそうしていない |

## セッション切替（A2・2026-08-04）

⌃` で起動。**既存の展開パネルを再利用**し、選択中の行に枠を出す（第2のウィンドウを作ると本体と状態を合わせ続ける手間が永久に残るため）。

| 項目 | 状況 | 備考 |
|---|---|---|
| 軽く押す（0.3秒未満・移動なし） | ✅ | 一覧が開いたままになり、矢印キーで選んで ↩ で移動 |
| 押しっぱなし | ✅ | 押すたびに次へ。修飾キーを離した瞬間にそのセッションへ移動 |
| Shift で逆順 | ✅ | 設定で切れる。切ると登録自体を外す |
| 開く位置 | ✅ | 現在のセッションではなく**次**から始める（1回押しで「もう片方へ」が成立する） |
