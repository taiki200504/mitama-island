# 参照製品パリティ・チェックリスト

Mitama Island の設定画面と周辺 UI を、有償の参照製品（Vibe Island 1.0.43）と同等の情報設計に揃えるための対応表。
各フェーズの受け入れ基準はこの表であり、表の行がすべて ✅ になった時点でパリティ完了とする。

## この文書の使い方

- **状態**: ✅ 実装済み（UI と挙動が両方動く） / 🟡 UI のみ（「準備中」バッジ付き・挙動は未実装） / ❌ 未着手
- **挙動依存**: 「UI を出すだけでは嘘になる」項目。`FeatureAvailability` に登録し、実装が入るまで disabled にする
- 参照製品の文言そのものは本書に転記しない。項目の**機能**を自分の言葉で記述する
- 参照製品の生の設定ツリー（文字列リソース・defaults ダンプ）は `.local-reference/` にローカル抽出してあり、gitignore 済み。公開リポジトリには入れない
